# 🧠 AI-LAB: Cerebro Evolutivo Agnóstico

Sistema autónomo de auto-mejora en tiempo de inferencia, independiente de modelo, arnés y hardware.

- **`CORE/`**: Motor evolutivo (`engine.sh`), buscador autónomo de papers en arXiv (`arxiv_scout.py`) y arnés interactivo (`harness.py`).
- **`BRAIN/`**: Memoria semántica comprimida en chino (`PRINCIPLES.md`, `TOOLS_MEMORY.md`, `PAPERS_DIGEST.md`) y configuración desacoplada (`CONFIG.env`).
- **`TASKS/`**: Retos aislados con verificación determinista.
