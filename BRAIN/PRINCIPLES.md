# 通用工程原则 (UNIVERSAL_PRINCIPLES)
- [环境约束] 仅用 Python 标准库，禁第三方库与子进程。
- [I/O 优化] 必用 `sys.stdin` 逐行读，弃 `open()` 消 I/O 开销。
- [算法核心] 利用哈希可加性将集合合并简化为加法运算。
- [并行加速] 利用群论特性实现集合哈希的并行累加优化。
- [系统调用] Windows 硬件查询优先 `ctypes`，禁 PowerShell。
- [校验规范] 调用系统工具前增加参数与路径校验层。
